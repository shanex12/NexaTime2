## 🚀 คุณสมบัติเด่น

- **Splash Screen アニメชัน** — หน้าปกสุดล้ำก่อนเข้าเว็บ พร้อมเอฟเฟกต์ Floating และ Pulse
- **Luxury Dark Theme** — โทนสีดำลึกตัดกับสีทองไล่เฉด ให้ความรู้สึกพรีเมียมและทรงพลัง
- **Glassmorphism** — พื้นผิวแบบกระจกฝ้า ดูทันสมัยและมีมิติ
- **Responsive Design** — รองรับทุกขนาดหน้าจอ ทั้งมือถือและเดสก์ท็อป
- **Smooth Scroll** — การเลื่อนหน้าแบบนุ่มนวลระหว่างแต่ละเซกชัน
- **Hover Animations** — การ์ดผลงานมีการยกขึ้นและเรืองแสงเมื่อนำเมาส์ชี้

## 📦 วิธีการติดตั้งและรัน

1. Clone repository นี้:
   ```bash
   git clone <repository-url>
   cd portfolio
   ```

2. เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ที่ต้องการ หรือใช้ Live Server ใน VS Code

3. (ตัวเลือก) อัปโหลดขึ้น Hosting เช่น GitHub Pages, Netlify, หรือ Vercel เพื่อเปิดเว็บสาธารณะ
